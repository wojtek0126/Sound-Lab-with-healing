# Product Overview

Sound Lab with Healing is a web-based application focused on sound exploration and an enjoyable, calming user experience. It combines sound-related functionality with a visually appealing interface featuring golden star details and day/night themes. It runs directly in a modern web browser without a traditional software installation.

- Live application: https://wojtek0126.github.io/Sound-Lab-with-healing/
- Repository: https://github.com/wojtek0126/Sound-Lab-with-healing
- License: BSD 2-Clause

## Main Features

- Sound generation and experimentation.
- Audio recording.
- WAV audio playback.
- Day/night visual themes.
- Compact, left-aligned day/night switch.
- Golden star visual elements.
- Custom golden healing-star browser favicon.
- Responsive browser-based interface.
- Synchronized minimum and maximum pitch controls to prevent invalid frequency ranges.
- English and Polish interface with a language selector (choice is remembered).
- Golden Frequencies presets with an animated golden-star effect.
- Upload and play your own WAV file with seek, rewind/forward 10 s and playback speed.
- Collapsible section panels.

## User Instructions

### Accessing the Application

Open https://wojtek0126.github.io/Sound-Lab-with-healing/ in a modern browser.

### Using the Application

1. Open the application in your browser.
2. Explore the available sound-generation features.
3. Experiment with the available sound settings.
4. Use audio playback to listen to generated sounds.
5. Use recording functionality where available.
6. Switch between day and night themes using the theme switch.

### Browser Compatibility

Recommended browsers: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari.

Some audio features may require user interaction before playback because of browser audio security policies.
