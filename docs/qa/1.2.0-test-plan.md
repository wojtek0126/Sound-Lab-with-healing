# 1.2.0 Test Plan

Planned testing areas for version 1.2.0. Results will be documented after execution.

Note: IDs QA-25 to QA-28 overlap with the accordion cases in [Test cases](test-cases.md). Renumber one set before importing both into a test-management tool.

| ID | Area | Test objective |
| --- | --- | --- |
| QA-25 | Refactoring | Verify existing functionality after file separation |
| QA-26 | Audio | Verify sound generation after refactoring |
| QA-27 | Recording | Verify recording, playback and download |
| QA-28 | Localisation | Verify English interface |
| QA-29 | Localisation | Verify Polish interface |
| QA-30 | Login | Validate required fields |
| QA-31 | Login | Validate email and password |
| QA-32 | Signup | Validate all required fields |
| QA-33 | Signup | Verify password matching |
| QA-34 | Signup | Verify password strength feedback |
| QA-35 | Signup | Verify terms acceptance |
| QA-36 | Forms | Verify submission is blocked when validation fails |
| QA-37 | Navigation | Verify login/signup navigation |
| QA-38 | Responsive UI | Test authentication screens on mobile |
| QA-39 | Regression | Verify existing sound functionality remains operational |
| QA-40 | Browser compatibility | Test supported browsers |
| QA-41 | UI polish | Buttons share one size and shape (exactly 340 x 48 px on desktop, 768px and wider); icon buttons unchanged |
| QA-42 | UI polish | Uppercase text applies per the design guidelines in English and Polish (notes and info box stay sentence case) |
| QA-43 | Player | Hint changes begin, loading, ready; resets on discard; status line does not repeat it |

| QA-46 | Notes | Section notes show the 20px gap above in all four sections |
| QA-47 | Responsive UI | Uppercase Polish labels and buttons fit at 320-430 px and on Android |
| QA-48 | Help | Section notes are hidden by default; the "?" icon shows and hides them by click/tap and keyboard on desktop and Android; labels follow the language; the icon is disabled while the section is closed and the note is hidden again after reopening |
