# ⭐ Sound Lab with Healing

A browser-based sound laboratory for exploring sound, creating relaxing audio experiences, and experimenting with sound generation and recording.

- Live application: https://wojtek0126.github.io/Sound-Lab-with-healing/
- Repository: https://github.com/wojtek0126/Sound-Lab-with-healing
- License: BSD 2-Clause (see [LICENSE](LICENSE))
- Current release: 1.1.0 (with post-release fixes); next: 1.2.0 (planned)

## Quick Start

Open the live application in a modern browser (Chrome, Firefox, Edge or Safari). To run locally, serve the folder over HTTP (locale files are loaded with `fetch()`):

```powershell
python -m http.server 8000
```

Then open http://localhost:8000.
